# Repository-Zweck

Öffentliche Dokumentation, Support-Issues und versionierte ZIP-Releases für JUJIES Arbeitsblätter. Kein entpackter Pluginquellbaum. Die vollständige Release-ZIP enthält Regeln, Skripte und 13 Beispiel-/Vorlagenpakete; „Source code (zip)“ von GitHub ist kein Plugininstaller.

# Pflege

- README, INSTALLATION und Releasehinweise auf den aktuellen Paketstand halten. Die Kurzanleitungs-PDF bei Änderungen am Bedienablauf aktualisieren; bleibt sie unverändert gültig, ihren älteren Stand ausdrücklich erklären.
- Deutschsprachiger Arbeitsablauf; andere Arbeitsblattsprachen ausdrücklich möglich, keine pauschale Sprachqualitätsgarantie.
- Verzeichnisregion Deutschland nicht mit Sprache oder weltweiter GitHub-Sichtbarkeit verwechseln.
- GitHub-Pilot und OpenAI-Verzeichniseinreichung sind getrennte Veröffentlichungswege. Keine Freigabe behaupten.
- Vor Releases vollständige ZIP, Metadaten, Vorlagenanzahl, lokale Ressourcen und Prüfsumme prüfen. Lizenznachweise erhalten. Keine privaten Materialien, Schülerdaten, Zugangsdaten oder internen Rechnerpfade veröffentlichen.
- Bereits veröffentlichte Assets nicht stillschweigend überschreiben. Neue Version bei Paketänderungen.
- Änderungen an Support-/Datenverarbeitung in DATENSCHUTZ nachvollziehen; GitHub ist ein öffentlicher Supportkanal.
